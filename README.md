WasteWise ♻️
WasteWise is a comprehensive application designed to track, analyze, and visualize waste management data efficiently.
Built with Python, it helps users monitor waste patterns, generate insightful analytics, and view interactive charts to support smarter environmental and operational decisions.

🚀 Features
Interactive Web Application (app.py): The core interface for users to interact with the system seamlessly.
Data Analytics (analytics.py): Processes and evaluates waste generation trends, metrics, and key performance indicators.
Data Visualization (charts.py): Generates dynamic charts and visual representations of waste data.
Database Integration (database.py): Manages persistent storage, data retrieval, and schema operations.
Sample Dataset (sample_waste.csv): Pre-loaded with sample waste data to test and demonstrate the application's capabilities out of the box.
